## Reglas del Proyecto

- Los scripts están en `/scripts-opus/`
- Los datos de productos están en `/productos/`
- El estado de publicaciones está en `/estado/`
- Los anuncios viejos (backup) están en `/anuncios/`
- La documentación vieja está en `/documentacion/`
- Las ideas y planes están en `/ideas-versiones/`
- El código de RevoRenew (extensión de Chrome de terceros, solo referencia) está en `/RevoRenew last update/`
